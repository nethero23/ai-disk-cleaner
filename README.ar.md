# Clearwisp: منظّف القرص الذي يفهم أدوات الذكاء الاصطناعي

**أداة مجانية ومفتوحة المصدر لتنظيف الأقراص على Windows، مصمَّمة لمطوّري الذكاء الاصطناعي، تعمل على C: وD: وكل الأقراص الأخرى. تعثر على المساحة التي تشغلها نماذج Ollama وHugging Face وLM Studio، وذاكرات التخزين المؤقت لـ Cursor وClaude Code وVS Code، وذاكرات pip وconda وnpm، والأقراص الافتراضية لـ WSL وDocker، ثم تحرّرها. الفحص أولًا، والقرار لك، ويمكن التراجع عن كل حذف.**

## لماذا

على حاسوب يُستخدم في أعمال الذكاء الاصطناعي، نادرًا ما تمتلئ الأقراص بالملفات المؤقتة التقليدية للنظام. ما يملؤها هو **أوزان النماذج اللغوية المحلية، وبيئات Python، وذاكرات التخزين المؤقت لمحررات الشيفرة الذكية، والأقراص الافتراضية لـ WSL وDocker**، وغالبًا ما تبلغ مئات الغيغابايت. لا تبحث CCleaner والأدوات المشابهة هناك، وWizTree يخبرك أي مجلد كبير لكنه لا يخبرك ما هو ولا إن كان حذفه آمنًا.

والأمر لا يقتصر على القرص C:. فمكتبات النماذج وبيئات conda وأقراص Docker ومجلدات `node_modules` في المشاريع ينتهي بها المطاف على D: وE: أيضًا. يفحص Clearwisp كل قرص تختاره.

يشرح Clearwisp كل غيغابايت: **أي نموذج، وأي بيئة conda، وذاكرة أي أداة، ومتى استُخدمت آخر مرة، وماذا يحدث إن حذفتها**. لكل عنصر مستوى أمان، ولا يُحذف شيء قبل أن تحدده، ويذهب المحذوف إلى سلة المحذوفات، ويمكن التراجع عن آخر تنظيف بنقرة واحدة.

## الميزات

### 🧠 يعرف مخلّفات أدوات الذكاء الاصطناعي (136 قاعدة، أكثر من 90 أداة)

| الفئة | الأدوات المدعومة |
|---|---|
| النماذج اللغوية المحلية | Ollama، Hugging Face (hub / datasets)، LM Studio، ModelScope، GPT4All، Jan، Msty، llama.cpp، vLLM، Xinference، Open WebUI، AnythingLLM، Cherry Studio، Chatbox |
| الصور / الصوت | ComfyUI، Stable Diffusion WebUI، Stability Matrix، Pinokio، Whisper، OpenAI CLIP |
| أدوات البرمجة بالذكاء الاصطناعي | Cursor، Windsurf، Claude Code، Codex، Gemini CLI، Qwen Code، GitHub Copilot، Cline، Roo Code، Kilo Code، Continue، Aider، Trae، Kiro، Zed، OpenCode، Antigravity، Goose |
| Python / تعلّم الآلة | pip، uv، conda، Poetry، PyTorch، Keras، Triton، PaddlePaddle، Jupyter، Kaggle، Gradio |
| تطوير عام | npm، pnpm، Yarn، Bun، Cargo، Go، Maven، Gradle، NuGet، Composer، Playwright، Puppeteer، Electron، JetBrains، VS Code |
| الحاويات | Docker Desktop، WSL (ضغط ext4.vhdx) |
| Windows | ذاكرة Windows Update، مجلد Windows.old، الملفات المؤقتة، ذاكرات برامج تشغيل NVIDIA / AMD / Intel، ذاكرات Edge / Chrome / Firefox، Office، Teams، OneDrive |

يقرأ التطبيق ملفات manifest الخاصة بـ Ollama، وبنية ذاكرة Hugging Face، وبيئات conda، ومجلدات نماذج LM Studio، ومساحات عمل Cursor، فترى **الأسماء الحقيقية للنماذج والبيئات** وليس أحجام المجلدات فقط.

### 🛡️ الأمان أولًا

- **فحص للقراءة فقط**: لا يكتب الفحص أي ملف.
- **ثلاثة مستويات أمان**: 🟢 آمن (ذاكرة مؤقتة بحتة تُعاد تلقائيًا) / 🟡 يمكن تنزيله مجددًا / 🔴 يحتاج مراجعة (بيانات مستخدم أو قد يكون قيد الاستخدام). لا يُحدَّد افتراضيًا إلا «آمن».
- **حماية سجل المحادثات**: يحتفظ `state.vscdb` في Cursor و`~/.claude/projects` في Claude Code بمحادثاتك. يُصنَّفان «يحتاج مراجعة» ويمكن تصديرهما قبل التنظيف.
- **كشف العمليات الجارية**: ينبّهك عندما تكون أداة ما قيد التشغيل بدل أن يحذف ملفات تستخدمها.
- **تراجع**: كل حذف يذهب إلى سلة المحذوفات مع سجل للتنظيف. تراجع عن آخر تنظيف بنقرة، أو استعد العناصر واحدًا واحدًا من صفحة السجل.
- **معاينة**: اطّلع على محتوى أي عنصر قبل حذفه.

### 💾 حرّر المساحة دون حذف

- **النقل إلى قرص آخر**: انقل نماذج Ollama وذاكرة Hugging Face وذاكرات pip / uv / conda وغيرها إلى D:. ينسخ التطبيق ويتحقق ثم يضبط `OLLAMA_MODELS` / `HF_HUB_CACHE` / `PIP_CACHE_DIR` وغيرها أو يترك نقطة وصل للمجلد، فتستمر كل أداة في العمل. يمكنك إعادتها في أي وقت.
- **إزالة تكرار النماذج بين الأدوات**: الأوزان نفسها الموجودة في ذاكرة HF وLM Studio وComfyUI تُدمج بروابط صلبة. تعمل كل الأدوات كما هي وتُستهلك المساحة مرة واحدة.
- **ضغط الأقراص الافتراضية لـ WSL وDocker**: الملف `ext4.vhdx` يكبر فقط. أعده إلى حجمه الحقيقي.

### ⚡ سهولة الاستخدام

- **كل الأقراص**: افحص C: وD: والأقراص الخارجية، أيّها حدّدت؛ ويعثر على النماذج والذاكرات المنقولة إلى أقراص أخرى من بنية مجلداتها
- عرض «أين ذهبت مساحتي؟» لكل قرص
- مراقبة النمو: يبيّن المجلدات التي تكبر، مع تنبيه عندما يتجاوز النمو الأسبوعي حدًّا معيّنًا
- النماذج غير المستخدمة: يعثر على النماذج التي لم تستخدمها منذ مدة طويلة
- تنظيف عميق للنظام: مخزن مكونات WinSxS، ونقاط الاستعادة، وملف الإسبات، وذاكرة تحسين التسليم، وذاكرة Windows Update
- المجلدات الكبيرة غير المعروفة: تظهر أيضًا المجلدات الكبيرة التي لا تعرفها أي قاعدة بعد، مع اقتراح قاعدة بنقرة واحدة
- البحث عن الملفات الكبيرة، ومخرجات البناء (`node_modules` و`target` و`.venv`…)
- تجميع حسب الأداة، وبحث، وفرز؛ فحص متوازٍ مع شريط تقدم وإمكانية الإلغاء
- أيقونة في شريط المهام، وفحص دوري في الخلفية، وتنبيه عند تجاوز حد معيّن، وتنظيف تلقائي اختياري للعناصر الآمنة (معطّل افتراضيًا)
- دليل عند التشغيل الأول، وملخص في جملة واحدة بعد كل فحص
- تحديث تلقائي داخل التطبيق، وتحديث القواعد عبر الإنترنت، وكتابة قواعدك الخاصة بصيغة TOML

### 🚫 لا يفعل أبدًا

لا تنظيف للسجل (Registry)، ولا نوافذ مزعجة، ولا برامج مرفقة، ولا رفع لقائمة ملفاتك. يجري الفحص والتنظيف محليًا، وتستخدم تحديثات التطبيق والقواعد GitHub. التحقق من إصدارات MCP في صفحة «أدوات الذكاء الاصطناعي» مفعّل افتراضيًا ويمكن تعطيله من الإعدادات. تُرسل أسماء الحزم فقط إلى npm / PyPI، ولا يُرسل محتوى الإعدادات مطلقًا.

## التثبيت

1. افتح [أحدث إصدار](https://github.com/nethero23/ai-disk-cleaner/releases/latest)
2. نزّل `*_x64-setup.exe` (موصى به، يدعم التحديث داخل التطبيق) أو ملف `.msi`
3. شغّله واضغط **فحص**

**النسخة المحمولة**: نزّل `*_x64-portable.zip` وفك الضغط وشغّل `AI Disk Cleaner.exe`. تُحفظ الإعدادات والسجلات في مجلد `data` المجاور. النسخة المحمولة لا تتحدث تلقائيًا.

المتطلبات: Windows 10 / 11 x64 مع WebView2 (مضمّن في Windows 11، ويتولاه المثبّت في Windows 10).

> المثبّت غير موقَّع رقميًا بعد، لذا قد يعرض SmartScreen رسالة «قام Windows بحماية الكمبيوتر». اضغط «مزيد من المعلومات ← التشغيل على أي حال». كل الشيفرة مفتوحة.

**قريبًا**: `winget install nethero23.AIDiskCleaner` و`scoop install aidc`.

## الأسئلة الشائعة

### امتلأ القرص C: (أو D:). كيف أعرف ما الذي يشغل المساحة؟
افتح «أين ذهبت مساحتي؟» واختر قرصًا، فيظهر توزيع المساحة حسب المجلدات (تظهر `Users\<أنت>\AppData\Local` و`Downloads` وغيرها منفصلة). ثم شغّل فحصًا لترى الاستهلاك حسب كل أداة وكل نموذج.

### أين يخزّن Ollama النماذج، وكيف أنقلها إلى قرص آخر؟
افتراضيًا في `C:\Users\<أنت>\.ollama\models`. اختر عنصر Ollama في نتائج الفحص، ثم «النقل إلى قرص آخر» واختر مجلدًا على D:. ينسخ التطبيق ويتحقق ثم يضبط `OLLAMA_MODELS`. أعد تشغيل Ollama وسيقرأ من الموقع الجديد.

### هل يمكنني حذف ذاكرة Hugging Face (`.cache\huggingface`)؟
نعم. تُصنَّف «يمكن تنزيله مجددًا»: تُنزَّل النماذج من جديد عند الحاجة. إن لم ترغب في إعادة التنزيل فانقلها (يضبط التطبيق `HF_HUB_CACHE`)، أو ادمج النسخ المكررة مع LM Studio / ComfyUI بميزة إزالة تكرار النماذج.

### يشغل Cursor عشرات الغيغابايت. هل يمكنني حذف `state.vscdb`؟
يمكن حذف ذاكرات Cursor وسجلاته وذاكرة تنزيل الإضافات بأمان. لكن `state.vscdb` يحتوي على **سجل محادثاتك كاملًا مع الذكاء الاصطناعي** (وردت تقارير عن بلوغه 77 غيغابايت). يُصنَّف «يحتاج مراجعة»، ولا يُحدَّد افتراضيًا، ويمكن تصديره أولًا.

### هل يمكنني حذف مجلد `.claude` الخاص بـ Claude Code؟
يحتوي `~/.claude/projects` على سجلات الجلسات (jsonl) ويُصنَّف «يحتاج مراجعة»؛ صدّرها أولًا إن أردت الاحتفاظ بها. أما ملفات الذاكرة المؤقتة فيمكن تنظيفها بأمان.

### كيف أمسح ذاكرة pip / conda / npm؟
تظهر في مجموعة Python / ذاكرات التطوير بمستوى «آمن»، وتُعاد في التثبيت التالي. تظهر بيئات conda بأسمائها وتاريخ آخر استخدام، فيمكنك أيضًا حذف البيئات التي لا تستخدمها.

### كيف أصغّر ملف `ext4.vhdx` الخاص بـ WSL أو Docker؟
الأقراص الافتراضية لا تصغر من تلقاء نفسها. اختر ملف vhdx واضغط «ضغط»: ينفّذ التطبيق `wsl --shutdown` ثم الأمر `compact vdisk` من diskpart (يتطلب صلاحيات المسؤول، ويعمل على Windows Home). لا تُمس البيانات بداخله.

### هل ينظّف C: فقط؟ هل يمكنه فحص D: وE:؟
يفحص أي قرص. حدّد الأقراص في «نطاق الفحص» (في الإعدادات وأعلى صفحة النتائج). يعثر على مكتبات النماذج والذاكرات المؤقتة والأقراص الافتراضية ومخرجات البناء والملفات الكبيرة على الأقراص الأخرى. وعندما تضيق مساحة C: يمكنك أيضًا نقل النماذج الكبيرة إلى قرص آخر.

### حذفت شيئًا بالخطأ. هل يمكنني استعادته؟
نعم. كل شيء يذهب إلى سلة المحذوفات. استخدم «التراجع عن آخر تنظيف» أو استعد العناصر منفردة من صفحة السجل.

### هل يمكن أن يُفسد Windows؟
الفحص للقراءة فقط. لا يُنظَّف إلا ما هو مدرج في القواعد، ولكل عنصر عواقب حذفه مكتوبة. لا يُحدَّد افتراضيًا إلا «آمن»، ولا يُمس السجل أبدًا، ويُنبَّه إلى الأدوات قيد التشغيل.

### هل هو بديل لـ CCleaner؟
يغطي ما لا يغطيه CCleaner: نماذج الذكاء الاصطناعي، وبيئات Python، وذاكرات محررات الذكاء الاصطناعي. وينظّف أيضًا الملفات الشائعة غير الضرورية في Windows. لا مشكلة في استخدامهما معًا.

### هل هو مجاني؟ هل فيه إعلانات أو قياس عن بُعد؟
مجاني، برخصة MIT، بلا إعلانات ولا برامج مرفقة. يجري الفحص والتنظيف محليًا، وتستخدم تحديثات التطبيق والقواعد GitHub. التحقق من إصدارات MCP في صفحة «أدوات الذكاء الاصطناعي» مفعّل افتراضيًا ويمكن تعطيله من الإعدادات. تُرسل أسماء الحزم فقط إلى npm / PyPI، ولا يُرسل محتوى الإعدادات مطلقًا.

### هل يدعم macOS / Linux؟
حاليًا Windows 10 / 11 فقط. محرك الفحص مكتوب بلغة Rust متعددة المنصات، لذا قد تُضاف منصات أخرى لاحقًا.
