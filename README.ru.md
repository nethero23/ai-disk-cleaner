# Clearwisp: очистка диска, которая понимает AI-инструменты

**Бесплатная программа с открытым исходным кодом для очистки дисков Windows, созданная для AI-разработчиков: C:, D: и любые другие диски. Находит и освобождает место, занятое моделями Ollama / Hugging Face / LM Studio, кэшами Cursor / Claude Code / VS Code, кэшами pip / conda / npm и виртуальными дисками WSL / Docker. Сначала сканирование, решение за вами, любое удаление можно отменить.**

## Зачем

На компьютере для работы с AI диск забивает не привычный системный мусор, а **веса локальных LLM, окружения Python, кэши AI-редакторов кода и виртуальные диски WSL / Docker**, часто сотни гигабайт. CCleaner и похожие программы туда не заглядывают; WizTree показывает, какая папка большая, но не говорит, что это и можно ли её удалить.

И дело не только в диске C:. Библиотеки моделей, окружения conda, диски Docker и `node_modules` из проектов оказываются и на D:, и на E:. Clearwisp сканирует все диски, которые вы выберете.

Clearwisp объясняет каждый гигабайт: **какая это модель, какое окружение conda, кэш какого инструмента, когда им пользовались последний раз и что будет, если его удалить**. У каждого пункта есть уровень безопасности, ничего не удаляется, пока вы не поставите галочку, удалённое попадает в Корзину, а последнюю очистку можно отменить одним щелчком.

## Возможности

### 🧠 Знает мусор AI-инструментов (136 правил, более 90 инструментов)

| Категория | Поддерживается |
|---|---|
| Локальные LLM | Ollama, Hugging Face (hub / datasets), LM Studio, ModelScope, GPT4All, Jan, Msty, llama.cpp, vLLM, Xinference, Open WebUI, AnythingLLM, Cherry Studio, Chatbox |
| Изображения / речь | ComfyUI, Stable Diffusion WebUI, Stability Matrix, Pinokio, Whisper, OpenAI CLIP |
| AI-инструменты для кода | Cursor, Windsurf, Claude Code, Codex, Gemini CLI, Qwen Code, GitHub Copilot, Cline, Roo Code, Kilo Code, Continue, Aider, Trae, Kiro, Zed, OpenCode, Antigravity, Goose |
| Python / ML | pip, uv, conda, Poetry, PyTorch, Keras, Triton, PaddlePaddle, Jupyter, Kaggle, Gradio |
| Общая разработка | npm, pnpm, Yarn, Bun, Cargo, Go, Maven, Gradle, NuGet, Composer, Playwright, Puppeteer, Electron, JetBrains, VS Code |
| Контейнеры | Docker Desktop, WSL (сжатие ext4.vhdx) |
| Windows | кэш Центра обновления Windows, Windows.old, временные файлы, кэши драйверов NVIDIA / AMD / Intel, кэши Edge / Chrome / Firefox, Office, Teams, OneDrive |

Программа читает манифесты Ollama, структуру кэша Hugging Face, окружения conda, папки моделей LM Studio и рабочие области Cursor, поэтому вы видите **настоящие названия моделей и окружений**, а не только размеры папок.

### 🛡️ Безопасность прежде всего

- **Сканирование только на чтение**: во время сканирования не записывается ни один файл.
- **Три уровня безопасности**: 🟢 Безопасно (чистый кэш, создаётся заново автоматически) / 🟡 Можно скачать заново / 🔴 Проверить (данные пользователя или возможно используется). По умолчанию отмечено только «Безопасно».
- **Защита истории чатов**: `state.vscdb` в Cursor и `~/.claude/projects` в Claude Code хранят ваши переписки. Они помечены «Проверить», и их можно экспортировать перед очисткой.
- **Проверка запущенных процессов**: предупреждает, если инструмент запущен, а не удаляет файлы, которыми он пользуется.
- **Отмена**: всё отправляется в Корзину с журналом очистки. Последнюю очистку можно отменить одним щелчком, отдельные пункты восстановить на странице истории.
- **Предпросмотр**: загляните внутрь любого пункта перед удалением.

### 💾 Освободить место без удаления

- **Перенос на другой диск**: перенесите модели Ollama, кэш Hugging Face, кэши pip / uv / conda и другое на D:. Программа копирует, проверяет, затем задаёт `OLLAMA_MODELS` / `HF_HUB_CACHE` / `PIP_CACHE_DIR` и т. д. или оставляет точку соединения каталога, так что все инструменты продолжают работать. Вернуть обратно можно в любой момент.
- **Удаление дубликатов моделей между инструментами**: одинаковые веса в кэше HF, LM Studio и ComfyUI объединяются жёсткими ссылками. Все инструменты работают, а место занимается один раз.
- **Сжатие виртуальных дисков WSL / Docker**: `ext4.vhdx` только растёт. Сожмите его до реального размера.

### ⚡ Удобство

- **Все диски**: сканирует C:, D:, внешние диски — какие отметите; по структуре папок находит модели и кэши, перенесённые на другие диски
- Обзор «Куда делось место?» для каждого диска
- Мониторинг роста: показывает, какие папки растут, и уведомляет, когда рост за неделю превышает порог
- Неиспользуемые модели: находит модели, которыми вы давно не пользовались
- Глубокая очистка системы: хранилище компонентов WinSxS, точки восстановления, файл гибернации, кэш оптимизации доставки, кэш Центра обновления Windows
- Нераспознанные большие папки: большие папки, которых ещё нет в правилах, тоже показываются, с предложением правила в один щелчок
- Поиск больших файлов, результаты сборки (`node_modules`, `target`, `.venv`…)
- Группировка по инструментам, поиск, сортировка; параллельное сканирование с прогрессом и отменой
- Значок в трее, фоновое сканирование по расписанию, уведомление при превышении порога, необязательная автоочистка безопасных пунктов (по умолчанию выключена)
- Подсказки при первом запуске и итог в одну фразу после каждого сканирования
- Автообновление в программе, онлайн-обновление правил, собственные правила в TOML

### 🚫 Никогда

Никакой очистки реестра, назойливых окон, встроенных сторонних программ и отправки списка ваших файлов. Сканирование и очистка выполняются локально; обновления приложения и правил обращаются к GitHub. Проверка версий MCP на странице «ИИ-инструменты» включена по умолчанию и может быть отключена в настройках. В npm / PyPI отправляются только имена пакетов, но не содержимое конфигураций.

## Установка

1. Откройте [последний релиз](https://github.com/nethero23/ai-disk-cleaner/releases/latest)
2. Скачайте `*_x64-setup.exe` (рекомендуется, поддерживает обновление из программы) или `.msi`
3. Запустите и нажмите **Сканировать**

**Портативная версия**: скачайте `*_x64-portable.zip`, распакуйте и запустите `AI Disk Cleaner.exe`. Настройки и журналы хранятся в папке `data` рядом. Портативная версия не обновляется автоматически.

Требования: Windows 10 / 11 x64 с WebView2 (встроен в Windows 11; в Windows 10 об этом позаботится установщик).

> Установщик пока не подписан, поэтому SmartScreen может показать «Система Windows защитила ваш компьютер». Нажмите «Подробнее → Выполнить в любом случае». Весь код открыт.

**Скоро**: `winget install nethero23.AIDiskCleaner` и `scoop install aidc`.

## Вопросы и ответы

### Диск C: (или D:) заполнен. Как узнать, что занимает место?
Откройте «Куда делось место?», выберите диск и получите разбивку по папкам (`Users\<вы>\AppData\Local`, `Downloads` и т. п. показываются отдельно). Затем запустите сканирование, чтобы увидеть занятое место по инструментам и моделям.

### Где Ollama хранит модели и как перенести их на другой диск?
По умолчанию в `C:\Users\<вы>\.ollama\models`. В результатах сканирования выберите пункт Ollama, затем «Перенести на другой диск» и папку на D:. Программа скопирует, проверит и задаст `OLLAMA_MODELS`. Перезапустите Ollama, и она будет читать модели из нового места.

### Можно ли удалить кэш Hugging Face (`.cache\huggingface`)?
Да. Он помечен «Можно скачать заново»: модели будут загружены снова при необходимости. Если не хотите скачивать заново, перенесите его (программа задаст `HF_HUB_CACHE`) или объедините дубликаты с LM Studio / ComfyUI функцией удаления дубликатов моделей.

### Cursor занимает десятки гигабайт. Можно ли удалить `state.vscdb`?
Кэши, журналы и кэш загрузки расширений Cursor можно удалять без риска. Но в `state.vscdb` хранится **вся ваша история чатов с AI** (сообщалось о размере до 77 ГБ). Он помечен «Проверить», по умолчанию не отмечен, и его можно сначала экспортировать.

### Можно ли удалить папку `.claude` от Claude Code?
В `~/.claude/projects` хранятся записи сеансов (jsonl), они помечены «Проверить»; если хотите их сохранить, сначала экспортируйте. Файлы кэша можно удалять без риска.

### Как очистить кэш pip / conda / npm?
Они отображаются в группе Python / кэши разработки как «Безопасно» и создаются заново при следующей установке. Окружения conda показываются с названием и датой последнего использования, поэтому ненужные окружения тоже можно удалить.

### Как уменьшить `ext4.vhdx` от WSL или Docker?
Виртуальные диски сами не уменьшаются. Выберите vhdx и нажмите «Сжать»: программа выполнит `wsl --shutdown`, а затем `compact vdisk` из diskpart (нужны права администратора; работает и в Windows Home). Данные внутри не затрагиваются.

### Программа чистит только C:? Можно ли сканировать D: и E:?
Можно сканировать любой диск. Отметьте диски в разделе «Область сканирования» (в настройках и вверху результатов). Библиотеки моделей, кэши, виртуальные диски, результаты сборки и большие файлы на других дисках тоже будут найдены. Когда на C: мало места, большие модели можно перенести на другой диск.

### Я удалил что-то по ошибке. Можно вернуть?
Да. Всё отправляется в Корзину. Нажмите «Отменить последнюю очистку» или восстановите отдельные пункты на странице истории.

### Может ли программа сломать Windows?
Сканирование только читает данные. Очищаются только папки из списка правил, для каждой описаны последствия. По умолчанию отмечено только «Безопасно», реестр не трогается, а о запущенных инструментах программа предупреждает.

### Это замена CCleaner?
Она делает то, чего не делает CCleaner: модели AI, окружения Python, кэши AI-редакторов. Обычный мусор Windows она тоже убирает. Пользоваться обеими можно без проблем.

### Это бесплатно? Есть реклама или телеметрия?
Бесплатно, лицензия MIT, без рекламы и встроенных программ. Сканирование и очистка выполняются локально; обновления приложения и правил обращаются к GitHub. Проверка версий MCP на странице «ИИ-инструменты» включена по умолчанию и может быть отключена в настройках. В npm / PyPI отправляются только имена пакетов, но не содержимое конфигураций.

### macOS / Linux?
Пока только Windows 10 / 11. Движок сканирования написан на кроссплатформенном Rust, так что другие платформы могут появиться позже.
